
# Website Style Guide

## 1. Colour Palette

| Colour | Hex Code | Usage |
|---|---|---|
| Red | `#BB1019` | Primary accent |
| Blue | `#063C7A` | Secondary accent |
| Off-white | `#F4F9F3` | Background |
| Green | `#4AB87E` | Accent |

## 2. Typography

### Sriraju
- Source: `assets/fonts` folder
- Use as a website font.

### Google Fonts
Embed the following fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Anek+Kannada:wght@100..800&family=Noto+Serif+Kannada:wght@100..900&display=swap" rel="stylesheet">
```

- **Anek Kannada** – Primary Kannada sans-serif.
- **Noto Serif Kannada** – Kannada serif typography.

## 3. UI Design

- Corner radius: `11px`
- Mobile-first responsive design.
- Simple, clean and consistent layouts.

## 4. Visual Texture

- Incorporate subtle electronic or digital media-inspired textures.
- Keep textures minimal and avoid visual clutter.

## 5. Responsive Approach

- Design for mobile screens first.
- Scale layouts appropriately for tablets and desktops.
- Maintain consistent typography, spacing and corner radius across devices.
